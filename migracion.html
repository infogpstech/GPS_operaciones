📖 Requisitos de Migración y Preparación de Entorno

Para desacoplar completamente GOs del backend de Google Apps Script y migrar a un servidor Linux/NodeJS/Python estándar con Base de Datos, siga las siguientes instrucciones:

  • Servidor de Aplicación: Node.js (v18+) o Python 3.10+ para montar el servidor API rest.
  • ORM sugerido: Prisma, Sequelize (para SQL) o Mongoose (para MongoDB).
  • Migración de Archivos: La estructura de DriveAño > Mes > Orden se puede migrar fácilmente a Amazon S3 o Azure Blob Storage, actualizando los punteros de enlaces de almacenamiento.

⚙️ Esquema SQL de Migración (PostgreSQL / MySQL)

Las siguientes instrucciones de SQL DDL crean las tablas equivalentes del Spreadsheet de GOS con indexación automática y constraints:

CREATE TABLE ordenes_trabajo (
    id VARCHAR(50) PRIMARY KEY,
    oi_id VARCHAR(50) UNIQUE NOT NULL,
    estado VARCHAR(50) DEFAULT 'Recepción',
    firma_tecnico TEXT,
    firma_cliente_recepcion TEXT,
    fecha_hora_recepcion TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    imei VARCHAR(50),
    sim VARCHAR(50),
    funcionalidades JSONB,
    segundo_gps VARCHAR(10) DEFAULT 'No',
    fotos JSONB,
    danos JSONB
);

CREATE TABLE historial_viajes_especiales (
    id VARCHAR(50) PRIMARY KEY,
    fecha DATE DEFAULT CURRENT_DATE,
    tecnico VARCHAR(100) NOT NULL,
    tipo_viaje VARCHAR(50) NOT NULL,
    destino VARCHAR(200) NOT NULL,
    orden_id VARCHAR(50) REFERENCES ordenes_trabajo(id)
);

🚨 Reversión Segura (Rollback) y Resolución de Problemas Frecuentes

Estrategia de Rollback: Si la migración falla a mitad del proceso, se debe ejecutar un Rollback atómico en el destino y mantener el Spreadsheet original de GOS activo. El Spreadsheet de GOS garantiza persistencia de contingencia (fallbacks) total.

Resolución de Problemas:

  • Error de Duplicación de Claves (VIN): Ejecutar el validador previo del asistente para consolidar chasis únicos en el historial.
  • Falta de Conectividad con Apps Script API: Incrementar el timeout de solicitudes HTTP en el proxy local a 30 segundos.
